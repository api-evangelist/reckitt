# Reckitt Benckiser (reckitt)

Reckitt Benckiser is a British multinational consumer-goods company focused on health, hygiene, and nutrition. Its portfolio includes globally recognised brands such as Lysol, Dettol, Mucinex, Strepsils, Nurofen, Veet, Finish, Vanish, Air Wick, Calgon, Durex, and Enfamil/Mead Johnson infant nutrition, sold in nearly 200 markets. Reckitt operates as a pure consumer packaged-goods company with retail and e-commerce distribution; it does not publish a public developer API or open partner integration portal at the corporate level - B2B trading-partner connectivity is handled via standard EDI / GDSN flows.
